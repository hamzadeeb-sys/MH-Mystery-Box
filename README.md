# MH-Mystery-Box
منصة تفاعلية ذكية لتخصيص وطلب صناديق الهدايا (Mystery Gift Boxes) لعلامة MH التجارية، مع ميزة تحويل بطاقة الطلب الفاخرة إلى صورة وإرسالها مباشرة عبر واتساب. (بالإنكليزية: Interactive personalized mystery gift box ordering platform for MH Brand with dynamic ticket rendering and WhatsApp export).
